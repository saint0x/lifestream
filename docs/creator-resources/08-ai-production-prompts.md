# AI Production Prompts

AI can help creators move faster.

But automation should come after taste.

Creators should first understand what good looks like manually, then automate the repeatable parts.

Do not use AI to mass-produce weak content.

Use AI to improve quality, consistency, speed, learning, and distribution. The creator benefit is not more output for its own sake; it is more creative surface area without surrendering judgment.

AI should support the thermal-energy model: higher-quality work, more aggressive distribution, better self-marketing, and smarter self-investment. It should help the creator create more heat without making the work feel cheap or automatic.

AI can also help identify collaboration leverage: which guests, co-creators, editors, directors, producers, experts, or adjacent creators could improve the work and create honest audience cross-pollination through Vanta's clickable credits.

The purpose is to make the creator's Vanta portfolio stronger and help the creator bring more real returning viewers to work that can be monetized through Vanta's advertising engine.

## Prompt 1: Manual First, Then Automation

```text
Help me identify what parts of my Vanta production process I should automate and what parts I should keep manual for now.

My series:
[describe]

My workflow:
[describe]

My current bottlenecks:
[describe]

Judge automation through the Vanta model: does it improve my premium profile, episode quality, clip volume, returning viewers, or advertiser value without lowering taste?

Evaluate:

- scripting;
- research;
- collaborator research and outreach;
- shot planning;
- editing;
- clip selection;
- captions;
- thumbnails;
- titles;
- visual enhancement;
- audio cleanup;
- translation;
- posting;
- analytics review;
- audience replies.
- credit and collaborator metadata.

For each area, tell me:

- should I do this manually first?
- what taste/judgment do I need to develop before automation?
- what can AI help with now?
- what should not be automated yet?
- what tools or workflow would help?
- how could automation increase output without lowering quality?
- where should I invest money instead of trying to automate badly?
- where should I use a real collaborator instead of an AI shortcut?

The goal is higher-quality content and more returning Vanta viewers, not lazy automation.
```

## Prompt 2: AI Visual Enhancement Plan

```text
Create an AI-assisted visual enhancement plan for my Vanta episode.

Episode:
[describe]

Current footage quality:
[describe]

Desired look:
[describe]

Constraints:
[budget, tools, skill level]

Prioritize enhancements that make the full Vanta episode and Vanta profile feel more premium, not effects that merely look flashy.

Suggest AI-assisted improvements for:

- color;
- upscaling;
- cleanup;
- titles;
- motion graphics;
- thumbnails;
- scene extensions if appropriate;
- B-roll creation if appropriate;
- subtitles;
- visual references;
- trailer assets.

For each suggestion include:

- why it helps;
- risk of looking fake or cheap;
- manual taste check required;
- whether it helps full-episode quality;
- whether it helps clip distribution.

Do not recommend AI effects that make the work feel generic, soulless, or deceptive.
```

## Prompt 3: Clip Automation Blueprint

```text
Design a clip automation workflow for my Vanta episodes.

Important: I want to learn the manual standard first, then automate.

Current process:
[describe]

Episode format:
[describe]

Platforms:
[list]

Design this so automation supports my Vanta growth engine: better clips, more consistent posting, stronger profile traffic, and more returning viewers.

Create:

- manual clip-selection checklist;
- what makes a clip worth cutting;
- naming convention;
- folder structure;
- caption template;
- hook template;
- CTA template;
- quality-control checklist;
- automation opportunities;
- tools I could use;
- what human review must remain;
- how to avoid posting low-quality automated clips.

The goal is to turn every good episode into many strong clips without lowering taste.
```
