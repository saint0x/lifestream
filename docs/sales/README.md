# Vanta Sales Bible

This folder is the operating system for selling Vanta's advertiser inventory.

The business docs explain why Vanta should exist. These sales docs explain how Vanta should package, pitch, sell, report, and renew advertising against exclusive creator programming.

## Core Sales Thesis

Vanta does not sell generic impressions.

Vanta sells:

> Verified creator-imported attention around exclusive premium programming.

That means the advertiser is buying a combination of:

- creator trust;
- exclusive content;
- measurable viewer attention;
- audience migration from the creator's existing channels;
- a repeatable media property rather than a one-off post;
- and reporting through Qualified Attention.

## Operating Rule

The sales organization should always protect the core flywheel:

```text
Creator brings audience
-> Audience watches exclusive programming
-> Vanta verifies Qualified Attention
-> Advertiser pays premium access
-> Creator earns meaningful revenue
-> Creator promotes harder
-> More creators join
```

Anything that does not strengthen this loop should be treated as secondary.
