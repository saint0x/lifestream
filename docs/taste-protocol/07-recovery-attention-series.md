# Recovery, Attention, And Series Systems

## 48. Recovery Protocol

Suppose the raw footage is poor.

Rank the preferred interventions:

- crop
- stabilize
- reframe
- punch in
- slow down
- speed up
- color correct
- denoise
- interpolate
- use B-roll
- use still imagery
- use graphics
- use audio only
- shorten dramatically
- omit entirely
- request pickup footage

Define:

1. What can be salvaged?
2. What should never be salvaged?
3. When is requesting more footage mandatory?
4. When should the narrative itself be redesigned around missing coverage?

## 49. Coverage Gaps

1. What substitutes are acceptable?
2. Can another moment be repurposed?
3. Can an insert cover the gap?
4. Can audio bridge the gap?
5. Can a title card solve it?
6. Can generative imagery ever be used?
7. If so, under what disclosure requirements?
8. When must the gap simply remain visible?
